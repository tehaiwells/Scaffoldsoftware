# Current scope

The revised brief supersedes Phase-1-only restrictions. This build extends the foundation into a persistent local logistics simulator.

Implemented: authentication and memberships; role/tenant/site boundaries; system settings; measured yard polygons; physical containers; synthetic catalogue/provenance/overrides and reviewed JSON import; opening stock; exact reservations and partial packing; forklift/crane resources; persisted movement; truck loading/trips; site inventory; returns; scoped stocktake/approval; append-only ledger; exports; notifications; pause/recovery; backup and test tooling.

Actual browser operation covered setup, opening stock, loading, delivery, unloading, return and an approved demonstration count of 100 → 95. Automated browser status is recorded separately in VALIDATION.md.

Do not treat this as blanket completion of every detail in the commercial brief. KNOWN_LIMITATIONS.md lists gaps including multi-line request UI, multi-yard/site editing, continuous worker movement, global search, further normalization and deployment hardening.

No manufacturer documents, rejected pick ticket, accounting, paid messaging, public deployment, AI runtime or engineering certification were used or added.
